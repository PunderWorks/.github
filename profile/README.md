<h1 align="center">Jessica's PunderWorks</h1>

<p align="center">
  Open hardware for makers and droid builders.
</p>

---

Jessica's PunderWorks is the home to a selection of fantastic offerings for makers and droid builders.
These designs are entirely open source and open to contribution.

## Projects

| Project | What it is |
|---|---|
| [Amidala](https://github.com/PunderWorks/Amidala) | ESP32-S3 droid control board and firmware, with a browser-based setup UI |
| [Snips Controllers](https://github.com/PunderWorks/SnipsControllers) | Wireless handheld controllers for droids, built to pair with Amidala |
| [DroidCANBridge](https://github.com/PunderWorks/DroidCANBridge) | Small, inexpensive CAN-to-UART bridge so non-CAN droid components can join a CAN bus |
| [DroidPowerSense](https://github.com/PunderWorks/DroidPowerSense) | Inline battery switch, protection and telemetry board, reporting over CAN FD and UART |
| [PowerBoards](https://github.com/PunderWorks/PowerBoards) | Small PCBs for power regulation and distribution |

## Contributing

Everything here is open source, and contributions are welcome. Issues, bug reports, design
suggestions and pull requests are all appreciated. Open an issue on the project you're interested
in to get started.
